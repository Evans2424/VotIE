# Citilink Sample Data

This directory contains **30 sample examples** from the Citilink test set for demonstration and quick evaluation purposes.

## Files

- `citilink_spans_sample/test_sample_30.jsonl` - 30 examples in span format
- `citilink_bio_sample/test_sample_30.jsonl` - 30 examples in BIO format

## Sample Statistics

- **Total Examples**: 30
- **Coverage**: 5 examples from each of 6 municipalities (M01-M06)
- **Total Entities**: ~50-100 annotated entities across all 8 entity types

## Full Dataset

⚠️ **Important**: This is only a small sample for demonstration purposes.

To access the **complete Citilink dataset** with:
- 1,798 training examples
- 552 development examples  
- 529 test examples

Please download from the official RDM repository:
**https://rdm.inesctec.pt/dataset/cs-2025-007**

## Usage

You can use these samples to:
- Test the model pipeline
- Verify data format compatibility
- Quick evaluation experiments

For full model training and comprehensive evaluation, download the complete dataset from RDM.
